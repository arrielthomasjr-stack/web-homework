To track down a rule that does nothing on a real site you can use the validator or inspect the code on the browser through the dev tool settings.

Why do real sites keep their CSS in one external stylesheet instead of inline styles or a <style> element on every page? Give at least two reasons, and name one situation where an inline style is still acceptable.

Real sites keep their CSS in one external stylesheet because a redesign means editing one stylesheet, not 200 HTML files and it makes downloading site pages faster by downloading the stylesheet once. The few times it can be acceptable is for a quick test ("does red work here?"), and in values that a script sets while the page runs.

In Challenge 4.8 the card started out wider than 320px, even though its CSS said width: 320px. Explain why, using the words content, padding and border, and explain what box-sizing: border-box changes.

That happen because by default (box-sizing: content-box), width sets only the content area which was 320px. Padding and border are added on top which expands in outside of the 320px. Meaning the contents (text or image) sets the size (width and height) by default. The padding is the space between the content and the border comes after that is set. On the other hand, with box-sizing: border-box, width includes the padding and border, and the content area shrinks to fit.
