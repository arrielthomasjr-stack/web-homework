Written answers

A classmate uploads a 4000 × 3000 photo straight from their phone and shows it 400 pixels wide on their project page. Explain what this costs the people who visit the page, and describe how you would fix it, using the ideas of dimensions, display size and srcset.

This makes visitors pages slow, especially on phones with weak signal, it also wastes their data plan and battery, and can make the layout jump while it loads. To fix it, resize the image’s actual dimensions to match its display size, with one copy at 400px and one at 800px for sharp high-density screens, and compress them, for example as WebP. Then give the browser the choices with sizes and srcset, and set width and height so space is reserved before the image arrives.

Explain the difference between captions, subtitles and a transcript, and who each one helps. Then explain why a page should never play a video with sound by itself.

Captions show the spoken words in the same language, plus key sounds. They help people who are deaf or hard of hearing, or anyone watching with the sound off. Subtitles translate the dialogue into another language and usually skip sound effects. They help people who don’t speak the video’s language. A transcript is a separate text version of the whole video. It helps users that are deaf and blind on braille displays, people who prefer to read or skim, and search engines. A page should never play a video with sound by itself because it drowns out screen readers, startles people and disrupts others nearby. WCAG requires that automatic audio longer than 3 seconds can be paused or stopped, so let the user start the video, or autoplay it muted with controls.

A designer says the new yellow buttons must be readable because their HSL lightness is 50%, the same as the blue ones. Explain why the lightness number is not enough, what you would measure instead, and why an error message should never be shown by color alone.

The lightness number is not enough because two colors with the same 50% lightness can look completely different. What should be measured instead is the contrast ratio between the text color and the button color and error messages should never be shown by color alone because about 1 in 12 men have some color blindness, so a red border may look the same as a normal one.

Explain the difference between Flexbox and Grid in your own words. Then name one layout from this homework where you would choose Flexbox and one where you would choose Grid, and say why.

Flexbox lays items out in one direction, a row or a column, and lets each item’s content decide how much space it takes. Grid lays items out in two directions at once, rows and columns. You define the structure first and then place items into it.

Explain what mobile-first CSS means, and give two reasons it is the recommended way to organize a responsive stylesheet.

Mobile-first CSS means writing the base styles for the smallest screen first, with no media query, and then adding min-width media queries that layer on changes as the screen gets wider. A phone gets just the simple one-column layout, while tablets and desktops get that plus the extra rules for their width. Two reasons why it is the recommended way to organize a stylesheet are, phones layout is usually the simplest and they often have slower connections and less processing power but are use widely.

Sass variables and CSS custom properties both store a value under a name. Explain one thing a custom property can do that a Sass variable cannot, and describe a project where you would still reach for Sass.

A CSS custom property lives in the browser, so it can change while the page runs. Sass variables exist only while compiling. In the finished CSS they are gone, so they can't change in a media query or from JavaScript. CSS custom properties can, which is why many projects now use custom properties even inside Sass. I think Sass should be used on a large site with a design system that has dozens of pages.
